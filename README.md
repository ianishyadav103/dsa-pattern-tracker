# dsa-pattern-tracker

A lightweight interactive dashboard to master Data Structures & Algorithms through structured pattern grouping and progress tracking.

---

* **Original List & Methodology:** Created by **Ashish Pratap Singh** ([@ashishps_1]([https://x.com/ashishps_1](https://www.youtube.com/@ashishps_1))) Adjusted slightly by trimming redundant problems and adding key replacements for better pattern balance.

* **Dashboard Design & Enhancements:** Developed with AI assistance (Gemini)


---

### What & Why
* **Purpose:** Track and master top-priority DSA patterns efficiently.
* **Smart Progression:** Moves sequentially from Linear Arrays & Stacks → Trees & Graphs → Backtracking → Advanced DP.
* **Active Learning:** Employs a 2–2–2 execution model (2 for concept, 2 for practice, 2 for mastery) to avoid autopilot solving.

### Key Features
* **Essential-First:** Groups high-frequency interview patterns first for maximum impact.
* **Local Storage:** Auto-saves problem progress and notes locally in your browser.
* **Import/Export:** Export progress to JSON for easy backup or transfer across devices.
